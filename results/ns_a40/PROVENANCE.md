## Reproducing the run

P_19 was wired (`9671e94`) after this run, fitted from T(39,20) and this
run's T(40,21). An unrestricted re-run would therefore fill H = 21 from
P_19 instead of enumerating it, and the check of P_0..P_18 against the
enumerated H = 21 column below would not be regenerated. `scripts/term.sh`
passes `--max-diag-k 18` on every phase for N ≥ 40 (`b2fde69`), so a re-run
at HEAD enumerates H = 21 as this one did. Anyone re-running by hand should
pass the same cap.

## The H = 20 row

On the phase C relaunch the driver re-entered the completed phase B in
resume mode, found no columns left, and rewrote `perheight/h20.out` from
an empty in-memory table, all zeros. The combine step refused the zeroed
file. The checkpoint `POLYCKPT.B` carries the full count table; its rows
T(20..39,20) match the a(39) run's enumerated H = 20 column, and `h20.out`
was rebuilt from it, giving T(40,20) = 2359769260803281210360136128699.
The engine fix is tested by `orchestrator/zero_harvest_test.go`.

A clean H = 20 run (`scripts/a40_h20_recheck.sh`; fresh run directory,
phase B's configuration, 48 cores, 43,747 s of sweep wall; output in
`recheck/`) reproduced the rebuilt `h20.out` byte for byte.

## Which cells have a second source

`results/provenance-table.md`, generated by `scripts/provenance_table.py`
and checked by `make gate-provenance`, lists for every cell of the triangle
which programs have recomputed it. In summary: heights 1..10 (355 cells)
match the fixed-height generating functions expanded to n = 40; heights
1..14 match the strip transfer matrix (469 cells, `results/second-sources.md`;
it shares the union-find rule in `core/transition.h`); heights 1..19 match
the coloring recount (`results/cutcount_b1/`), which shares no code and
never decides connectivity; H = 20 is the standalone re-run above, the same
program twice; H = 21 has one enumeration; heights 22..40 are closed forms
P_0..P_18, each checked on an enumerated cell outside its fit. The mod-2
congruence of `results/symmetry-classes.md` holds at every cell.
