# results/ — the evidence, and the record of what it shows

Two kinds of thing live here. **The banked data**: the triangle itself
(`triangle.txt`), the per-term ledgers `ns_a20/` through `ns_a40/` and `a41/`
(each with its own `PROVENANCE.md`: which binary, which host, which
validations), the second-source rows under `cutcount_b1/` and `motley-par/`,
b-file staging (`b*_upload.txt`), and the logs and tables the gates read. **The
record**: the fifteen documents below, which are the mathematics this project
found, each written to be read on its own.

Start with `confidence.md` if the question is how far a(n) can be trusted.

| file | what it holds |
|---|---|
| `confidence.md` | how well each term is supported, in plain terms, and where the residual risk sits |
| `provenance-table.md` | generated: for every cell of the triangle, what confirms it and by which source |
| `residual-cells.md` | generated: the cells with one enumeration behind them, both senses of "residual", computed in one place |
| `second-sources.md` | the three programs that recount parts of the triangle, what each reaches, and what the recounts leave uncovered |
| `diagonal-formula.md` | the closed forms of the triangle's diagonals: shape, onset, the constants and how they are pinned |
| `below-onset.md` | the error term below the onset, where the formula is not yet exact |
| `undertow.md` | pinning the formulas from cells below their onset, which is how a(41) was reached |
| `arithmetic-structure.md` | the triangle mod 3 and mod 5, denominators, integrality, the ternary spine |
| `growth-constant.md` | λ: the certified two-sided bound, the series estimates, and what closes the gap |
| `symmetry-classes.md` | the free, one-sided, bilateral and asymmetric companions, and the congruences behind them |
| `perimeter.md` | both ends of the site-perimeter table, and the defect gradings |
| `subclasses.md` | directed, convex and stratified polyplets, holes, and the poly-time tier |
| `anisotropic-not-dfinite.md` | the height-anisotropic generating function is not D-finite: the theorem and its certificates |
| `closed-doors.md` | every route past the enumeration that was tried and closed, with the obstruction and the measurement that closed it, and the open problems |
| `oeis-candidates.md` | sequences staged for OEIS, none submitted |
| `l-paper-verifier-coverage.md`, `p-paper-verifier-coverage.md` | how much of each manuscript's arithmetic its verifier actually reads, measured by perturbation |

`docs/consolidation-plan.md` says which older records were merged into these
and at which commit each is readable.
