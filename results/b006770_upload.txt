# A006770: number of fixed n-celled polyplets (king-move animals). a(1)-a(35).
# Method (uniform): column/kink-carry transfer-matrix engine. Each maxn=N run
# recomputes the whole height triangle T(n,H) -- low heights swept directly,
# top heights via validated closed-form height-diagonals -- and byte-matches
# the live OEIS b-file (a(1)-a(18)) and all prior computed terms through
# n=N-1.

# machine, three-architecture Redelmeier fleet run (24000 disjoint shards,

# digit-for-digit against the transfer-matrix values; the two counters share
# no counting logic. a(23)-a(35) are single-algorithm (transfer matrix /
# kink-carry): cross-ISA (ARM+x86) and cross-run consistent, and each term's
# newest height-diagonal cell is predicted exactly by a closed form fitted
# only on earlier terms (a(33)'s top swept cell matches held-out P_15; P_16,
# fitted on a(33)-a(34), predicted the later holdouts T(35,19) and T(36,20)
# exactly). NOT algorithm-independently confirmed -- Redelmeier is O(a(n))
# and infeasible much past n ~ 22.

# k=17, whose closed form has no held-out cross-check until a(37), so it is
# one grade weaker; see the entry Comments. Independent confirmation welcome.
