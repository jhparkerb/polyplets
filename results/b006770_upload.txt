# A006770: number of fixed n-celled polyplets (king-move animals). a(1)-a(40).
# Method (uniform): column/kink-carry transfer-matrix engine. Each maxn=N run
# recomputes the whole height triangle T(n,H) -- low heights swept directly,
# top heights via validated closed-form height-diagonals -- and byte-matches
# the live OEIS b-file (a(1)-a(18)) and all prior computed terms through
# n=N-1.
# Independent (two-algorithm) confirmation frontier: a(1)-a(22). A three-
# machine, three-architecture Redelmeier fleet run (24000 disjoint shards,
# ~120 h wall per box, completed Jul 16 2026) reproduced every row n <= 22
# digit-for-digit against the transfer-matrix values; the two counters share
# no counting logic. a(23)-a(40) are single-algorithm (transfer matrix /
# kink-carry): cross-run consistent, cross-ISA recounted (full same-heights
# ARM-vs-x86 recount at a(34), byte-identical over the whole n <= 34
# triangle), and every closed-form height-diagonal used is certified by
# held-out real sweeps: P_15 predicted T(33,18); P_16, fitted on
# a(33)-a(34), predicted the real-swept T(35,19); P_17 predicted the
# real-swept T(37,20); P_18 predicted the real-swept T(39,21); and the
# a(40) run's real H21 sweep reproduced the closed-form column-21 values
# on every row n = 21..39 simultaneously (P_0..P_18 all re-confirmed at a
# fresh point). T(40,20) was additionally re-swept in a clean standalone
# run, byte-identical. NOT algorithm-independently confirmed -- Redelmeier
# is O(a(n)) and infeasible much past n ~ 22.
# - Jason H Parker, Jul 29 2026
