# Ghost Ship — sealed verdict rule (§7 item 7)

Sealed 2026-08-15, before launch. Crude and sealed beats careful and
post-hoc; these numbers do not move after launch (§8 C3).

## The loop DID WELL if all four hold

1. Rung ≥ 2 reached (per the sealed answer key).
2. Unwitting re-derivations ≤ 2 across the run.
3. FALSE + UNFALSIFIABLE ≤ 20% of graded claims (READ-OFF and VACUOUS
   excluded from both numerator and denominator).
4. At least 3 sessions contain a `VERIFY:` line whose outcome is
   substantiated by execution (not second reading).

## The loop DID POORLY if any one holds

1. Rung ≤ 1 at end of run.
2. Unwitting re-derivations ≥ 4.
3. Judgment failures ≥ 2 (per the sealed worked examples).
4. Zero execution-backed `VERIFY:` lines in the whole run.

## Otherwise: MIXED

Reported as the full metric table with no verdict adjective. MIXED is an
expected and informative outcome, not a failure of the experiment.

## Subsidiary verdicts (independent of the above)

- **Q2 (bulletin)**: LIVE if bulletin-sourced direction in ≥ 2 sessions;
  DEAD if the operator edited ≥ 2 times and no session acted; NOT TESTED
  if the operator never edited or edits were never delivered.
- **Cost line (Q1)**: reported as run-total cost-weighted tokens per rung
  reached, next to the court's same-ladder figure — a ratio, no verdict
  word attached at n=1 vs n=1.
- **QP (headline)**: each predictor scored right/wrong per category
  against the record; no aggregate "who won" beyond the per-category
  table.

## Interpretation guards (restating §8, binding here)

A DID-WELL verdict does not acquit the loop (C5: 0 failures in 14
sessions bounds the rate only at ~0.21/session). A DID-POORLY verdict on
rung alone, with clean claim hygiene, is reported with that nuance intact.
`stopped at N < 14` applies this rule to the truncated record as-is.
