%N Axxxxxa Number of fixed n-cell polyplets (A006770) with no holes (hole-free), 4-connected-background convention.
%C Axxxxxa A polyplet (or polyking) is a set of unit cells connected through edges or corners (king moves); A006770 counts the fixed ones. Here we count those whose 4-connected complement has no bounded component, i.e. simply-connected (hole-free) polyplets.
%C Axxxxxa Column k=0 of the polyplets-by-number-of-holes triangle [draft Axxxxxx]. Equals A006770(n) for n <= 3 and A006770(n) minus the number of holed n-polyplets for n >= 4; the smallest holed polyplet is the 4-cell diamond, so a(4) = A006770(4) - 1 = 110 - 1 = 109. - _Jason H Parker_, 2026
%C Axxxxxa Exact via a column transfer matrix carrying the Euler characteristic as a hole index (project thread #28), validated byte-identical to a per-animal background flood fill (n <= 14), with a(n) + (number of holed n-polyplets) = A006770(n); terms given through n = 18, of which n = 15..18 are independently reproduced on a second CPU architecture (clang/ARM vs gcc/x86, byte-identical). - _Jason H Parker_, 2026
