# `literature/` — the literature library

The papers this project **reads**. Nothing here is ours.

The papers this project **writes** are one letter away, in [`paper/`](../paper/).
If you came here looking for a manuscript, that is where it is.

- `INDEX.txt` — every PDF, with where it came from, when, and what it is cited
  for. A file that is not in the index has not been read.
- `MISSING.md` — papers that were looked for and could not be obtained, with the
  reason and what was done instead. `docs/engineering-standards.md` requires a
  citation that cannot be checked to be recorded here rather than quietly
  dropped or quietly trusted.

Bibliographic detail for the manuscripts is kept once, in
`paper/shared/refs.bib`, and is taken from `INDEX.txt`.
