%N Axxxxxx Irregular triangle read by rows: T(n,k) = number of fixed n-cell polyplets (king-move/"polyplet" animals, A006770) having exactly k holes, n >= 1, 0 <= k <= A_kmax(n); a hole is a bounded 4-connected component of empty cells (the topological-dual convention, matching A389193 for ordinary polyominoes).
%C Axxxxxx A "polyplet" (or polyking) is a set of unit cells connected through edges or corners (king moves); A006770 counts the fixed ones. Here they are stratified by number of enclosed holes, where the background uses 4-connectivity (so a diagonal wall of cells does seal a region). This is the primary convention; the companion 8-connected-background stratification is a separate (not yet computed) triangle.
%C Axxxxxx Row sums give A006770. Column k=0 (hole-free polyplets) is A_0 [draft]; column k=1 is A_1 [draft]. The polyomino (edge-connected) analogue of the holed total is A389193.
%C Axxxxxx Computed exactly by a column transfer matrix carrying the Euler characteristic as a hole index (project thread #28); validated byte-identical to an independent per-animal flood fill for n <= 14, with row sums equal to A006770 (incl. the confirmed A006770(19)); exact through n = 18, with rows n=15..18 independently reproduced on a second CPU architecture (clang/ARM vs gcc/x86, byte-identical). - _Jason H Parker_, 2026
%C Axxxxxx Generating-function structure: the contribution of bounding-box-height-exactly-H, k-hole animals is a rational function G_{H,k}(x); e.g. G_{3,1}(x) = (x^4 + 2*x^5 - 2*x^7 - x^8)/(1 - 8*x + 20*x^2 - 14*x^3 - 8*x^4 + 18*x^5 + 3*x^6 - 16*x^7 + 6*x^8 + 6*x^9 - 3*x^10 - 2*x^11 + x^12). The order of G_{H,k} is c_H*(k+1) with c_H = 6, 20, 68, 185, 537 for H = 3..7. Summed over all heights the columns A_k(x) are not expected to be D-finite (as for A006770).
