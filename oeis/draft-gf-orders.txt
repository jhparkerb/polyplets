%N Axxxxxd Degree of the reduced denominator Q_H(x) of the rational generating function G_H(x) = Sum_{n>=1} B_H(n)*x^n, where B_H(n) is the number of fixed n-cell polyplets (king-move animals, A006770) of bounding-box height exactly H; equivalently the order of the linear recurrence satisfied by H |-> B_H(n).
%C Axxxxxd A "polyplet" (polyking) is a set of unit cells joined through shared edges or corners. For each fixed bounding-box height H the strip transfer matrix has a bounded state space, so G_H(x) is rational and a(H) = deg Q_H is finite. The terms here are H = 1..10.
%C Axxxxxd Lifetime-3 law: Q_H factors as N_{H-2}*N_{H-1}*N_H into pairwise-coprime "atom" polynomials, so a(H) = deg N_{H-2} + deg N_{H-1} + deg N_H, where deg N_H = 1, 2, 4, 9, 29, 68, 181, ... [draft Axxxxxe]. Equivalently, every irreducible factor of any Q_H divides exactly three consecutive denominators (Q_h, Q_{h+1}, Q_{h+2}) and no others.
%C Axxxxxd The "3" is the width of a second finite difference. Writing V_H(n) for the number of n-cell polyplets placed in an H-row strip (counted WITH vertical position), height-exactly-H is the second difference B_H = V_H - 2*V_{H-1} + V_{H-2}; V_H is rational with reduced denominator N_H, which is why three consecutive atoms appear.
%C Axxxxxd Lifetime 3 is universal across finite-range lattice-animal classes (rook, king, and even the gapped knight all give lifetime 3, with different atoms); only the atom degrees are lattice-specific. Verified for H <= 7; the exactly-3 / atom-irreducibility refinement is observed, not proved. - _Jason H Parker_, 2026
