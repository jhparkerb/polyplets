%N  Triangle read by rows: T(n,H) = number of fixed polyplets (king-move /
    8-connected polyominoes) of n cells whose bounding box has height exactly H,
    1 <= H <= n.

%C  Row sums give A006770 (fixed polyplets by cell count): Sum_{H=1..n} T(n,H) = A006770(n).
%C  Left column is all 1s (height 1 = a horizontal strip of n cells, A000012).
%C  Right diagonal T(n,n) = 3^(n-1) (A000244): height exactly n forces one cell per
    row, king-connected, with 3 horizontal offsets (-1,0,+1) at each of the n-1 steps.
%C  The top diagonals have closed forms: T(n,n-k) = P_k(n)*3^(n-1-3k) for n >= 2k+1,
    with P_k an integer-valued polynomial of degree k and leading coefficient 25^k/k!
    (shape proved by an exact walk-plus-clusters decomposition; constants derived
    ab initio for k<=5, fitted and holdout-validated for 6<=k<=18). In particular
    T(n,n-1) = (25n-45)*3^(n-4) for n >= 4.
%C  How the entries were obtained, and how far each is confirmed. The short
    heights of each row are enumerated by a column transfer matrix. For n >= 24
    the tall heights, those above the line H > n/2, are not enumerated: they are
    evaluated from the closed forms above, whose shape and range of validity are
    proved and whose two constants per level are fixed from computed entries of
    the same triangle. A second program sharing no counting logic with the
    first, a transfer matrix that counts by coloring cells and never decides
    connectivity, recounts every entry of height at most 19; for 23 <= n <= 39
    that leaves every entry either recounted by it or given by a closed form
    pinned on its entries. Three entries of the table have one enumeration
    behind them and no closed form: T(39,20), T(40,20) and T(40,21).

%C  Verified: every row sum matches the banked A006770(n) for n<=40, and the
    row sums for n<=18 match the A006770 DATA field as OEIS serves it today
    (that entry has no author-uploaded b-file; its b-file is auto-synthesized
    from DATA); edges T(n,1)=1 and T(n,n)=3^(n-1) confirmed for all n<=40.

%F  T(n,1) = 1.  T(n,n) = 3^(n-1).  Sum_{H=1..n} T(n,H) = A006770(n).
%F  T(n,n-1) = (25n-45)*3^(n-4) for n >= 4; generally T(n,n-k) = P_k(n)*3^(n-1-3k)
    for n >= 2k+1 with deg P_k = k, lead 25^k/k! (see the project report).
