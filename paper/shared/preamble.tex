% Fonts before microtype, and microtype's expansion only when the fonts under
% it are scalable. A TeX Live install without lmodern (or cm-super) answers a
% TS1 glyph request -- numprint pulls textcomp, so every paper here makes one --
% by running METAFONT and handing back a BITMAP font, and microtype then dies
% with "auto expansion is only possible with scalable fonts". That is how
% `make -C paper` failed on the clean-clone run (ayr, TeX Live 2022/Debian,
% 2026-08-18): L1 built, L2 stopped at a display in mid-document.
%
% With lmodern present: T1, scalable Computer Modern, expansion on, best output.
% Without it: expansion off, and the PDFs still build. A reader gets the better
% branch by installing texlive-latex-recommended (Debian) or the lmodern port.
\IfFileExists{lmodern.sty}
  {\usepackage[T1]{fontenc}\usepackage{lmodern}\usepackage{microtype}}
  {\usepackage[expansion=false]{microtype}}

% Repo paths and Lean identifiers are long unbreakable \texttt runs, and a
% paragraph that ends on one has nowhere to break: that was 24 overfull boxes
% across the nine L papers, eight of them past 60pt (about 2cm into the
% margin). \emergencystretch gives TeX a third pass with extra glue rather
% than letting the line stick out. Set before the tables below are widened,
% so what it is covering is the prose case.
\setlength{\emergencystretch}{3em}

% Theorem environments.  One counter shared across kinds, so that a reference
% like "Theorem 4" is unambiguous in a paper that also has lemmas and
% propositions.

% Repo-path citations.  Every one of these must resolve in the tree that ships
% with the paper; `make gate-citations` checks the markdown, and
% paper/verify_claims.py checks the manuscripts.
% Paths and Lean identifiers are long unbreakable \texttt runs, and they were
% most of the residual overfull boxes: \emergencystretch cannot divide a word
% that has no break in it. They are written with escaped underscores, and \_ is
% a control sequence whose meaning is resolved at typesetting time even inside
% an already-tokenised argument (a \caption, say), so redefining it inside
% \texttt gives TeX somewhere to divide. No hyphen is inserted -- a path with a
% hyphen in it would read as a different path -- and pdftotext still recovers
% the path intact, which matters for a PDF a reader copies a path out of.
\let\LTTT\texttt
\renewcommand{\texttt}[1]{{\def\_{\char`\_\discretionary{}{}{}}\LTTT{#1}}}
\newcommand{\repo}[1]{\texttt{#1}}
